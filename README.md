# LinguaLeap 🚀 (Аналог LingQ / Readlang / Lexpring)

Полноценное кроссплатформенное приложение на **Flutter (Dart 3)** для эффективного изучения иностранных языков через чтение текстов и просмотр YouTube-видео с интерактивными субтитрами, контекстным ИИ-переводом и интервальным повторением (SRS).

---

## 📱 Ключевые возможности

1. **Библиотека материалов:**
   - Импорт видео из YouTube: автоматическое извлечение названия ролика, дорожек субтитров (ручных и автосгенерированных) и покадровых таймкодов через `youtube_explode_dart`.
   - Импорт произвольных текстов, статей, фрагментов книг или диалогов с автоматической разбивкой на предложения.
   - Локальное сохранение в реляционную SQLite базу данных.

2. **Интерактивный ридер и видеоплеер:**
   - **Адаптивный макет:**
     - На широких экранах (Windows / десктоп / планшеты) — двухколоночный режим: слева закреплен плеер, справа интерактивный текст с автопрокруткой.
     - На смартфонах (Android) — плеер закреплен сверху, субтитры прокручиваются снизу.
   - **Синхронизация с видео:** плеер опрашивается каждые 300 мс, активная реплика подсвечивается и мягко центрируется на экране (`Scrollable.ensureVisible`).
   - **Мгновенная перемотка:** клик по таймкоду любого сегмента вызывает `seekTo` в плеере.
   - **Токенизация слов:** каждое слово кликабельно (`Wrap` / `InkWell`), сохраняя естественную верстку текста.
   - **Визуальная индикация словарного запаса:**
     - Желтый/оранжевый фон — слова в процессе изучения (`learning`).
     - Мягкий зеленый фон — выученные слова (`known`).
     - Обычный текст — новые незнакомые слова.

3. **Контекстный перевод через LLM API:**
   - При клике на слово сначала проверяется локальная БД `words`.
   - Если слово новое, отправляется запрос к LLM (OpenAI, OpenRouter, Groq, DeepSeek, Ollama) с контекстом всего предложения.
   - ИИ возвращает нормализованную форму (лемму), точный контекстный перевод, часть речи, альтернативные значения и грамматический комментарий.

4. **Интервальные повторения (SRS) и карточки (Flashcards):**
   - Алгоритм SM-2 для расчета коэффициента легкости (`ease_factor`) и интервалов (`interval_days`).
   - Режим тренировки флеш-карточек с кнопками оценки: *Снова*, *Трудно*, *Хорошо*, *Легко*.
   - Полнотекстовый поиск по словарю, фильтрация по статусам и редактирование.

## 🛠 Технологический стек

- **Flutter & Dart 3** (null safety, clean code architecture).
- **База данных:** `sqflite` + `sqflite_common_ffi` (с поддержкой FFI на Windows / Linux / macOS).
- **State Management:** `Provider` (чистое разделение `ChangeNotifierProvider` для настроек, библиотеки и словаря).
- **YouTube субтитры:** `youtube_explode_dart`.
- **YouTube плеер:** `youtube_player_iframe`.
- **Сеть:** `dio` для HTTP-запросов к LLM.
- **Хранилище настроек:** `shared_preferences`.

## 📂 Структура проекта

```
lib/
├── main.dart                          # Точка входа, FFI-инициализация, глобальные провайдеры
├── models/
│   ├── material_item.dart             # Модель материала (YouTube / Text)
│   ├── segment.dart                   # Модель сегмента текста с таймкодами (startMs, durationMs)
│   └── word_item.dart                 # Модель слова в словаре с полями SRS
├── services/
│   ├── db_service.dart                # SQLite сервис (CRUD для materials и words, индексы)
│   ├── llm_service.dart               # Сервис работы с LLM API (OpenAI / OpenRouter / Ollama)
│   ├── settings_service.dart          # Сервис SharedPreferences (ключи, url, модель, языки)
│   ├── srs_service.dart               # Алгоритм интервальных повторений SM-2
│   └── youtube_service.dart           # Парсер субтитров и метаданных YouTube
├── utils/
│   └── text_tokenizer.dart            # Юникод-токенизатор слов и сплиттер предложений
├── widgets/
│   └── word_span_widget.dart          # Интерактивное кликабельное слово с подсветкой статуса
├── screens/
│   ├── home_navigation_screen.dart    # Адаптивная навигация (NavigationRail на ПК / NavigationBar на мобилке)
│   ├── library_screen.dart            # Экран списка сохраненных материалов
│   ├── import_material_dialog.dart    # Диалог импорта (YouTube / Свой текст)
│   ├── reader_screen.dart             # Двухрежимный ридер и YouTube-плеер с таймкодами
│   ├── word_sheet.dart                # Нижняя шторка / диалог детального перевода слова
│   ├── dictionary_screen.dart         # Экран словаря, фильтрации и поиска слов
│   ├── flashcards_screen.dart         # Интерактивные карточки повторения (SRS)
│   └── settings_screen.dart           # Экран настроек API, провайдеров, модели и языков
```

## 🚀 Запуск и сборка

1. Установите зависимости:
   ```bash
   flutter pub get
   ```

2. Запуск на Windows:
   ```bash
   flutter run -d windows
   ```

3. Запуск на Android:
   ```bash
   flutter run -d android
   ```

4. Сборка релизной версии:
   - **Windows:** `flutter build windows --release`
   - **Android APK:** `flutter build apk --release`
